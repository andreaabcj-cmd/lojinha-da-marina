# Página do Facebook · Lojinha da Marina

| Campo | O que colocar |
|---|---|
| Foto do perfil | `marca/perfil.png` (720×720) |
| Foto de capa | `marca/capa.png` (1640×624) |
| Nome da página | Lojinha da Marina (aula) |
| Categoria | Loja de presentes (ou "Site de compras e varejo") |
| Apresentação (até 101 letras) | Loja fictícia para aulas de Meta Pixel 🧪 Canecas, camisetas e ecobags de mentirinha. |
| Site | https://andreaabcj-cmd.github.io/lojinha-da-marina/ |
| Botão de ação | "Comprar" → mesmo endereço do site |

**Por que "(aula)" no nome e "fictícia" na apresentação:** deixa claro para qualquer pessoa que não é uma loja
de verdade, ninguém tenta comprar e a página não parece estar se passando por uma empresa real.

Para recriar as imagens: `python _ferramentas/gerar_marca.py`
